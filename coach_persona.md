# My Coach — Preferences

Edit this file freely in plain English. The coach reads it every time (both the
chat and the weekly-plan generator), so anything you write here shapes how it
advises you. No code or restart needed — just save the file.

## My focus
- My #1 goal is **running**. Everything else is supporting context, not a goal.

## When you build my training program, take these into account:
- **Cycling** — I cycle most days (commuting / fitness). It genuinely tires me
  out, so treat it as training load. Don't put a hard run the day after a long
  or hard ride; an easy spin can count as recovery. If my cycling volume is
  high, leave less room for hard running.
- **Sleep & recovery** — look at my recent sleep score, HRV, and resting heart
  rate. If recovery is poor (short sleep, HRV trending down, resting HR up), make
  the running easier or add rest. If I'm well-recovered, I can handle harder work.
- **Calories burned** — use my daily energy expenditure as context for how much
  load I'm under. (Note: this is calories *burned*, not food eaten — I don't log
  intake, so don't assume my diet.)

## How I like advice
- Be concise and specific, lead with my actual numbers and dates.
- Tell me plainly when I'm overdoing it or under-recovered.
- Plans are suggestions — I'll accept, edit, or regenerate them.
